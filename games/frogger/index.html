Five lily pads. Three lives.
One very busy crossing.

Ready to cross. Select Start game.

HOW TO CROSS

Arrow keys / WASD to hop, or use the direction buttons. P / Escape pauses; R restarts. Keyboard controls work while the game board is focused.

  • Dodge traffic, then ride the logs across the river. Water is not safe!
  • Land in the center of an empty lily pad at the top. Fill all five to advance.
  • Each crossing has a time limit. Cars, water, occupied pads, and running out of time cost a life.

Every new level is faster. The game pauses when you leave the tab.

NO DOWNLOADS. NO COINS. JUST ONE MORE HOP.
